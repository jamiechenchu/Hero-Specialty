Focus

Score = points × weight, where 5% = 1 pt, 10% = 2 pts, 20% = 4 pts. Troop stats apply to every type. Keep the lowest weight above half the highest so a bigger card always beats a smaller one. Set a weight to 0 to ignore that type.

Pattern reference

Rows read left to right, columns top to bottom. Row and column versions are separate cards and both count. The same card twice (e.g. two Green-Yellow-Purple rows) counts once.
